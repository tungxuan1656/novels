# Decision Document

Own the rationale for one durable decision.

```markdown
# <Decision>

**Status**: <proposed, accepted, replaced>

## Context

<Facts that require a decision.>

## Decision

<Chosen option and boundary.>

## Alternatives

| Option | Reason not chosen |
|---|---|
| <option> | <reason> |

## Consequences

- <Positive or negative effect.>
```

Update current architecture documents after an accepted decision changes canonical design.
